# Kết quả thực nghiệm

Mỗi lần chạy nên có thư mục hoặc tiền tố riêng, ví dụ:
`S02_baseline_seed1_YYYYMMDD/`

Lưu:
- Cấu hình dùng để chạy
- Lệnh chạy
- Seed và tham số
- Log stdout/stderr
- CSV dữ liệu thô
- Trạng thái thoát chương trình
- Ghi chú lỗi hoặc điều kiện môi trường

Không ghi đè dữ liệu gốc. Biểu đồ phải được tạo từ dữ liệu lưu trong thư mục này.
