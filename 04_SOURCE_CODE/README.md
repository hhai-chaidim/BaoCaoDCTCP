# Source code

- `original/`: bản gốc không chỉnh sửa, gồm source tác giả nếu có.
- `modified/`: code do dự án sửa/triển khai.
- `scripts/`: script chạy, phân tích CSV hoặc vẽ biểu đồ.
- Ghi phiên bản NS-3, commit/hash nguồn gốc, lệnh build/run và thay đổi.
- Không lưu build artifacts lớn nếu không cần; ưu tiên giữ log và dữ liệu cần tái lập.
